# Frontend - Sistem Peminjaman Ruangan Kampus

Frontend web untuk Sistem Peminjaman Ruangan Kampus menggunakan React + TypeScript.

---

## Fitur

- Tampilkan daftar peminjaman
- Tambah peminjaman
- Detail peminjaman
- Edit & Delete peminjaman
- Update status peminjaman
- Riwayat + Search & Filter

---

## Tech Stack

- React + TypeScript
- Vite
- React Router DOM
- Fetch API

---

## Instalasi

```bash
git clone https://github.com/farahsns19/2026-peminjamanruangan-frontend.git
cd 2026-peminjamanruangan-frontend
npm install
```

# Menjalankan Project
npm run dev

Frontend berjalan di:
http://localhost:5173
